# 妙控板电量管家 · 视觉原型

本阶段交付界面原型与工具图标，用于确定视觉和交互方向。

## 设计方向

- Windows 桌面小工具，浅色界面、薄荷绿强调色、深绿色文字。
- 主窗口提供「总览 / 电量历史 / 设置」导航。
- 总览展示设备名称、当前电量、上次更新时间、刷新按钮与电量趋势。
- 历史曲线支持 24 小时 / 7 天 / 30 天筛选。
- 低电量提醒支持启用开关与阈值；默认设计值为 20%。
- 采样间隔默认设计值为 5 分钟。
- 支持开机自启、关闭窗口后驻留托盘。
- 托盘菜单提供当前电量、打开主窗口、立即刷新、自启开关与退出。
- 工具图标以深绿色圆角底板、银白触控板和电池徽标构成。

## 交付文件

- `trackpad-battery-prototype.png`：主界面及托盘、提醒设置的组合原型。
- `trackpad-battery-icon-source.png`：通过本地生图辅助脚本生成的原始图标。
- `trackpad-battery-icon.png`：透明背景处理后的应用图标。
- `trackpad-battery.ico`：Windows 多尺寸图标，包含 16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256 像素。

原型中的 76%、历史曲线、记录天数和通知内容均为示意数据，不代表当前设备读数。图片展示设计方向，具体文本与控件会在桌面工具实现中精确排版。

## 生成方式

原型与原始图标由本地生图辅助脚本生成，该脚本不纳入 Git。原型使用宽幅界面设计提示词；图标单独生成后，使用 Pillow 处理背景透明度及导出 ICO，不改变主体设计。仓库已包含所需图片和 ICO，可直接构建桌面应用。
